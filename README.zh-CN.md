# RecLLM-Agent：推荐领域 Agentic RAG

> 代码快照发布说明：仅含筛选源码，不含模型、数据、日志或凭据。

RecLLM-Agent 是一个面向推荐系统知识问答的检索增强 Agent 项目，探索混合检索、重排、工具编排、引用审计和受门槛约束的答案改写。

## 主要能力

- BM25 与稠密检索、融合和重排
- 基于图的检索、工具调用与答案生成流程
- 引用检查、回归测试和实验审计

## 运行

按项目依赖清单安装后，通过环境变量配置模型服务。大型模型、语料、向量索引、运行日志和真实凭据不包含在发布版中。

## 结果口径

历史分数和实验状态以对应审计报告为准；候选模型或实验对照不等于生产模型，也不构成完整事实正确性证明。
