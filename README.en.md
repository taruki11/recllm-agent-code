# RecLLM-Agent: Agentic RAG for Recommendation Knowledge

> Code-only source snapshot. Models, datasets, run logs, and credentials are excluded.

RecLLM-Agent explores retrieval-augmented agents for recommendation-system question answering, including hybrid retrieval, reranking, tool orchestration, citation auditing, and gated answer revision.

## Features

- BM25 and dense retrieval, fusion, and reranking
- Graph-based retrieval, tool-use, and answer-generation workflow
- Citation checks, regression tests, and experiment audits

## Run

Install dependencies from the project manifest and configure the model service through environment variables. Large models, corpora, vector indexes, run logs, and real credentials are excluded from a release.

## Results

Treat historical scores and experiment status according to their corresponding audit reports. Candidate models and controlled experiments are not production models and do not prove complete factual correctness.
